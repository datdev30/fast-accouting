# FastAccounting - Tablet Client

Ứng dụng FastAccounting được tối ưu hóa cho tablet (iPad, Android tablet).

## Đặc điểm

- UI được thiết kế riêng cho màn hình tablet
- Hỗ trợ cả chế độ portrait và landscape
- Touch-friendly với các element có kích thước phù hợp
- Tối ưu hóa cho iPad Pro 11" và các tablet tương tự

## Cài đặt

```bash
npm install
```

## Chạy development server

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Cấu trúc

- `src/pages/` - Các trang được tối ưu cho tablet
- `src/components/` - Components hỗ trợ responsive cho tablet
- `src/index.css` - Styles với breakpoints cho tablet
